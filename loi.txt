- Requested scope: https://www.googleapis.com/auth/drive.readonly

**1. Scope Justification**

MeloWave is an Android music player that allows users to access and play audio files stored in their personal Google Drive accounts.

The `drive.readonly` scope is required for the following features:

- Browse existing Google Drive folders and nested subfolders directly within the application.
- Discover supported audio files across the user's Drive folder hierarchy.
- Select an entire folder and collect audio files from its subfolders into a music playlist.
- Read and stream audio files directly from Google Drive.
- Access previously authorized Drive content without requiring users to individually select every audio file through Google Picker.

Our existing `drive.file` integration only allows access to files specifically selected or authorized for the application. This does not fully support browsing the user's existing Drive folder hierarchy and discovering audio files that have not been individually selected.

The narrower `drive.metadata.readonly` scope is insufficient because audio playback requires reading the actual file content, not just metadata.

MeloWave only requires read access for these features. The `drive.readonly` functionality does not modify, delete, or change the sharing permissions of users' Drive files.

**2. OAuth Scope Alignment**

We have prepared a dedicated review build that explicitly requests the `drive.readonly` scope, corresponding to the scope submitted for verification.

Our existing production version continues using the previously implemented `drive.file` integration.

The new restricted-scope functionality is being tested separately to avoid affecting existing production users.
